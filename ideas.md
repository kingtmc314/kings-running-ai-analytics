<text>
**Design Movement:** Precision Instrument / Data-Driven Minimalism

**Core Principles:**
1. Data is the hero — every pixel serves the numbers
2. Dark navy base with high-contrast accent for critical metrics
3. Typographic hierarchy as the primary navigation cue
4. Micro-interactions that confirm every data point

**Color Philosophy:** Deep navy (#0B1426) background with electric blue (#3B82F6) as the primary accent. Amber (#F59E0B) for warnings and PRs. Emerald (#10B981) for positive trends. The palette evokes precision sports equipment and professional timing systems.

**Layout Paradigm:** Persistent left sidebar with icon + label navigation. Main content uses a 12-column grid with asymmetric card placement — wide analytics panels on the left, narrow stat cards stacked on the right.

**Signature Elements:**
1. Glowing metric cards with subtle inner-shadow halos
2. Animated number counters on data load
3. Thin horizontal rule separators with gradient fade

**Interaction Philosophy:** Instant feedback. Hover states reveal secondary data. Click transitions use 180ms ease-out slides.

**Animation:** Cards entrance with staggered fade-up (30ms delay per card). Chart bars animate from zero on mount. Number counters tick up over 800ms.

**Typography System:** `Space Grotesk` (700) for display metrics, `Inter` (400/500) for body copy, `JetBrains Mono` for pace/time values.

## Response 3 — SELECTED
<response>
<text>
**Design Movement:** Premium Sports Dashboard / Dark Glassmorphism

**Core Principles:**
1. Depth through layered glass cards on a rich dark background
2. Color-coded zones for instant physiological context
3. Sidebar navigation with smooth active-state transitions
4. Charts as visual storytelling, not just data display

**Color Philosophy:** Deep slate (#0F172A) base with subtle blue-violet gradient. Accent colors match heart-rate zones (blue → green → yellow → orange → red). White text on dark glass creates a premium sports-watch aesthetic.

**Layout Paradigm:** Fixed left sidebar (64px collapsed / 240px expanded) + scrollable main content. Dashboard uses a masonry-inspired card grid — stat cards in a 4-column row, full-width charts below, then 2-column detail panels.

**Signature Elements:**
1. Glass cards with `backdrop-blur` and subtle border glow
2. Zone-colored progress bars and badges
3. Animated sparklines in stat cards

**Interaction Philosophy:** Fluid and responsive. Sidebar items scale on hover. Chart tooltips appear with a 100ms fade. Form inputs glow on focus.

**Animation:** Page transitions: 200ms fade + 8px slide-up. Card entrance: staggered 40ms delay. Number counters: 600ms ease-out. Chart bars: 400ms ease-out from zero.

**Typography System:** `Outfit` (700/800) for display numbers, `DM Sans` (400/500) for body, `JetBrains Mono` for pace/time/HR values.
</text>

## Selected Design: Premium Sports Dashboard / Dark Glassmorphism

The chosen philosophy is **Response 3** — a premium dark sports dashboard with glassmorphism depth, zone-coded colors, and fluid animations. This approach best serves a serious runner's analytics tool: the dark base reduces eye strain during long analysis sessions, the zone colors provide instant physiological context, and the glass card aesthetic communicates professional precision without sacrificing warmth.
